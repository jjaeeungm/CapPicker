CapPicker 2.1.0 - Tiny, fast, and useful only.
One ~185 KB EXE. No installer, no account, no cloud.

CapPicker 2.1.0 - 작고 빠르며 유용한 기능만.
약 185KB 단일 EXE. 설치·계정·클라우드 불필요.

Capture exactly what you need, pick colors precisely, and annotate immediately.
필요한 화면을 정확히 캡처하고, 색상을 정밀하게 확인하고, 바로 표시·편집하세요.

Features / 주요 기능
- Rectangle (Alt + Shift + S), fixed-size, window, full-screen, last-region, scroll capture
- Screen color picker (Alt + Shift + C) and image-local picker: live HEX/RGB, pixel grid, 6x-128x zoom
- Pen, highlighter, shapes, arrow, check, text, eraser, crop, rotation, undo/redo
- Image zoom up to 1000% (Ctrl + mouse wheel, Ctrl + 0 resets)
- CapPicker-style print preview + standard Windows print dialog
- 사각형/고정크기/윈도우창/전체화면/지난영역/스크롤 캡처, 화면·이미지 컬러피커,
  펜·형광펜·도형·화살표·텍스트·지우개·자르기·회전·되돌리기, 최대 1000% 확대, 인쇄 미리보기

Language / 언어
- Default: follow the Windows display language automatically (English elsewhere).
- F1 opens Help; language selection lives in Settings (Auto / 한국어 / English).
- 한국어(ko-*) Windows에서는 한국어 UI가 표시됩니다.

Shortcuts / 단축키
- Rectangle capture: Alt + Shift + S / Screen color picker: Alt + Shift + C / Help: F1
- Copy: Ctrl + C / Save: Ctrl + S / Print preview: Ctrl + P / Undo: Ctrl + Z / Redo: Ctrl + Y

Settings / 설정
- Gear icon at the right of the top HEX/RGB result.
- Minimize: Taskbar (default) / Tray. Close: Tray (default) / Exit app.
- Performance: Normal (default) / Low-spec PC optimization.
- Stored in %LocalAppData%\CapPicker\settings.txt and language.txt.
- 상단 HEX/RGB 결과 오른쪽의 톱니 아이콘에서 설정합니다.

Version / 버전
- Product version: 2.1.0
- Assembly/File version: 2.1.0.0
- Window title: CapPicker 2.1.0

Build
1. Extract the ZIP.
2. Run BUILD.cmd.
3. CapPicker.exe is created in the same folder and launched.
